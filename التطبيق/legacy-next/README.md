# تطبيق تكة

MVP ويب عربي متجاوب يجرّب حلقة الجزيرة والتعلم والبناء. المحطات الثلاث محتوى تجريبي محايد؛ لا تدّعي تغطية منهاج الصف أو مادة كاملة.

## التشغيل المحلي

```powershell
npm install
npm run dev
```

افتح `http://127.0.0.1:3000`. يحفظ وضع الضيف التقدم على هذا الجهاز. لا يحتاج التشغيل المحلي إلى حساب أو مفاتيح Supabase.

## التحقق المحلي

```powershell
npm run content:validate
npm run test:content
npm run typecheck
npm run lint
npm run build
npm run test:e2e
```

اختبارات ولي الأمر السحابية اختيارية؛ تتخطى نفسها افتراضياً حتى تجهّز مشروعاً وحساب اختبار منفصلاً وتفعّل مسار الحسابات.

## أنبوب المحتوى وتدقيق الحزم (المرحلة P2)

توضع حزم المحتوى بصيغة JSON مهيكلة داخل مجلد `content/packs/`. الحزمة المعتمدة الحالية هي:
- `content/packs/g1-foundational-sample-pack.json`: عينة استكشافية محايدة للصف الأول تضم 3 محطات موزعة على اللغة العربية والرياضيات والحكايات، وموسومة بصراحة كـ `unreviewed_neutral_sample` لتوضيح أنها لم تخضع لمراجعة تربوية بشرية بعد.

### أوامر التحقق من المحتوى:
```powershell
npm run content:validate # فحص بنيوي وترابطي لكافة الحزم المحلية عبر CLI
npm run test:content     # تشغيل اختبارات الوحدة للمدقق والمحمل والحالات المعطوبة
```

**تنبيه منهجي وتربوي:**
- نجاح الفحص الآلي يضمن السلامة التقنية والترابطية ومطابقة مخططات Zod فقط.
- لا يعد التدقيق الآلي بديلاً عن المراجعة التربوية واللغوية البشرية المتخصصة.
- لا تدّعي الأداة أو الحزمة تغطية منهاجية ولا تحسب نسب تغطية لعدم وجود خريطة معتمدة لهذه العينات.

## حسابات الأسرة والمزامنة (مؤجلة)

طلب المالك تأجيل ربط حسابات الأسرة والمزامنة السحابية. لذلك لا يستدعي التطبيق Supabase ولا يعرض واجهات التسجيل افتراضياً، حتى لو كانت مفاتيح المشروع موجودة محلياً.

يبقى كود التكامل والمخططات محفوظاً للمرحلة اللاحقة. لا تفعّل المسار قبل موافقة المالك واستكمال إعداد المشروع والبريد والنشر. عند استئناف العمل، استخدم `.env.local` فقط:

```env
NEXT_PUBLIC_TAKKA_CLOUD_ACCOUNTS_ENABLED=true
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
SUPABASE_SECRET_KEY=
RESEND_API_KEY=
RESEND_FROM_EMAIL=
NEXT_PUBLIC_APP_URL=http://127.0.0.1:3000
```

المفتاح السري يبقى على الخادم. لا تضع مفاتيح حقيقية في `.env.example` أو ملفات المصدر، ولا تضف أي ملف `.env*` إلى Git.

للمراجعة قبل الاستئناف، راجع مرجع المشروع وإعداد SMTP وروابط إعادة التوجيه قبل تطبيق أي migration أو تشغيل ربط CLI.
