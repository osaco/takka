## 1. ما استوعبته من الوثائق (الخلاصة التنفيذية)

| القرار من الوثائق | التطبيق في النواة |
|:---|:---|
| تكة **محرك إتقان** يلبس عالمًا كرتونيًا — لا بنك أسئلة | `src/domain/mastery/` — قاعدة 3 مستقلة × جلستين × يومين، وحالات وصفية بلا درجات |
| **المحرك أولًا ← المدقّق ← الشاشة** | بُني بهذا الترتيب تمامًا، وكل طبقة معزولة عن التي فوقها |
| المكدس: React + TS strict + Canvas 2.5D، وPhaser/Three مؤجّلان | لا أثر لهما في الحزمة؛ القوالب `dom/svg/canvas2d` فقط |
| العقد: النص العربي في DOM فوق Canvas | `WorldStage` يرسم بحرًا وجزرًا فقط؛ كل الأسماء والأزرار DOM |
| ممنوع الأحمر الصارخ واللوم والسلاسل العقابية | `theme.ts` + `index.css`: برتقالي لطيف + wiggle + «نوقف هون» نجاح |
| «تكة» متغيرة الطول بحسب الصف | `session/builder.ts`: صغار 4–6د / وسط 7–10د / كبار 11–15د |
| الحزمة = صف + مادة + إصدار + بيان صدق | `content-packs/g1-*-v1.0/pack.json` + `scopeNote` يصرّح «ليست المنهاج الكامل» |
| Dexie خلف مستودع مجرّد + تصدير/استيراد JSON | `data/` + `export-import.ts` ببصمة FNV-1a |
| الجزر تُشتق من المحتوى المنشور فقط | `registry.ts` يبني الخريطة من الحزم المُجتازة للمدقّق فقط |
