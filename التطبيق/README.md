# تطبيق تكة

هذه هي النسخة النشطة المبنية بـReact وTypeScript وVite. الكود التشغيلي في `src/`، ومحتوى الصف الأول التجريبي في `src/content-packs/`، والفحوص في `tests/`.

## التشغيل

من جذر المستودع:

```powershell
npm install --prefix التطبيق
npm run dev
```

يمكن تشغيل الأوامر التالية من جذر المستودع أيضًا:

```powershell
npm run build
npm run test
npm run check
```

## حدود المحتوى

حزم المحتوى الموجودة عينات أولية موثقة النطاق. اجتياز المدقق الآلي يعني سلامة البنية والروابط فقط؛ ولا يعني اعتمادًا تربويًا أو تغطيةً كاملةً للمنهاج.

## النسخة السابقة

احتُفظ بنموذج Next.js السابق وإعداداته واختباراته في `legacy-next/` حتى تبقى تغييرات الفرع المحلي قابلة للمراجعة. لا يستخدم التطبيق النشط هذه الملفات.
