## ما الذي يقرأه الفريق؟

ابدأ بـ`تكة.md` لفهم دستور المنتج، ثم راجع `SPEC.md` للنطاق الحالي و`DESIGN.md` للنظام البصري. كود التطبيق الفعلي في `التطبيق/`. مرحلة المحتوى الحالية ما زالت عينة محايدة؛ لا تُنسب المحطات الثلاث إلى منهاج أو صف معتمد.

## ترتيب المحتوى

- `takka-project-brief.md` و`takka-team-workflow.md` — ملخص المنتج وسير عمل الفريق.
- ملفات `takka-*/SKILL.md` في هذا المجلد — مهارات أساسية قابلة لإعادة الاستخدام.
- `OpenMausBot/` — حزمة إعداد الفريق ونسخ المهارات حسب الدور.
- التقارير التي ينتجها الفريق تحفظ في `العمل/تقارير البوتات/`؛ راجع فهرسها هناك.
