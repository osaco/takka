```
### Prompt 2 — عالم Canvas 2.5D أولي

```
أنشئ عالم Canvas 2.5D أولي لتطبيق "تكة".

المطلوب:
1. ملف src/runtime/world/WorldStage.tsx
   - مكون React يرسم Canvas 2D
   - يعرض خلفية بحر متدرج (sea-sky إلى island-sand)
   - يرسم جزيرة عائمة واحدة في المركز بأسلوب 2.5D (شكل بيضاوي مع ظل)
   - يُضيف حركة موج خفيفة (sin wave)
   - يستخدم requestAnimationFrame لتحديث 60fps

2. ملف src/runtime/world/projection.ts
   - دوال نقية لتحويل إحداثيات العالم إلى إحداثيات الشاشة
   - input: { worldX: number, worldY: number, zoom: number, panX: number, panY: number }
   - output: { screenX: number, screenY: number }
   - دالة عكسية: screenToWorld

3. ملف src/runtime/world/islands.ts
   - بيانات الجزيرة الأولى (الموضوع: حرف الباء)
   - type Island = { id: string, nameAr: string, subject: string, x: number, y: number, state: 'sleeping' | 'awakening' | 'blooming', unlockProgress: number }
   - دالة getIslandState(island: Island, skillStates: Record<string, SkillState>): Island['state']

4. ملف src/runtime/screens/world-map-screen.tsx
   - مكون React يستخدم WorldStage
   - يعرض جزيرتين على الأقل (حرف الباء + حرف التاء)
   - عند النقر على جزيرة: يطبع في console "Opened: name"
   - زر "عودة" كبير (≥56dp) في أعلى يسار الشاشة

معايير القبول:
- [ ] pnpm dev يعمل بدون أخطاء
- [ ] WorldStage يُرسم بـ 60fps على Chrome DevTools Performance
- [ ] الجزيرة تتحرك بموجة خفيفة (amplitude ≤ 5px)
- [ ] النصوص العربية تظهر بشكل صحيح
- [ ] لا يوجد console errors
```

### Prompt 3 — Zustand Store أساسي

```
أنشئ Zustand store لإدارة حالة التطبيق الأساسي.

ملف: src/runtime/store/app-store.ts

```typescript
import { create } from 'zustand'

type Screen = 'splash' | 'world-map' | 'island' | 'activity' | 'parent-gate' | 'settings'

interface AppState {
  currentScreen: Screen
  setCurrentScreen: (screen: Screen) => void
  
  isSoundEnabled: boolean
  toggleSound: () => void
  
  isLowPerformanceMode: boolean
  setIsLowPerformanceMode: (v: boolean) => void
}

export const useAppStore = create<AppState>((set) => ({
  currentScreen: 'splash',
  setCurrentScreen: (screen) => set({ currentScreen: screen }),
  
  isSoundEnabled: true,
  toggleSound: () => set((s) => ({ isSoundEnabled: !s.isSoundEnabled })),
  
  isLowPerformanceMode: false,
  setIsLowPerformanceMode: (v) => set({ isLowPerformanceMode: v }),
}))
```

اختبار:
```typescript
import { describe, it, expect } from 'vitest'
import { useAppStore } from '../src/runtime/store/app-store'

describe('AppStore', () => {
  it('starts with splash screen', () => {
    expect(useAppStore.getState().currentScreen).toBe('splash')
  })

  it('can change screen', () => {
    useAppStore.getState().setCurrentScreen('world-map')
    expect(useAppStore.getState().currentScreen).toBe('world-map')
  })

  it('can toggle sound', () => {
    const initial = useAppStore.getState().isSoundEnabled
    useAppStore.getState().toggleSound()
    expect(useAppStore.getState().isSoundEnabled).toBe(!initial)
  })
})
```

## 📋Anti-patterns الممنوعة في هذه المرحلة

| ممنوع | البديل |
|:---|:---|
| استخدام Redux أو Context API | Zustand فقط |
| إضافة Three.js أو Phaser | Canvas 2D فقط |
| إضافة Dexie أو IndexedDB | Zustand فقط في P0 |
| إضافة كيفر أو API calls | لا شَبَكية في P0 |
| استخدام React Native | Web أولاً، Capacitor لاحقاً |
| تضمين صور PNG ثقيلة | SVG + CSS gradients |
