# 🔄 خط أنابيب المحتوى — «تكة»

> **الإصدار:** 1.0 — 20 تشرين الأول 2026

---

## 1. نظرة عامة

خط أنابيب المحتوى هو قلب المشروع التشغيلي. كل نشاط يمر عبر 6 مراحل قبل أن يصبح جزءاَ من التطبيق. أي مرحلة تفشل = النشاط لا يُبنى.

### التدفق العام

```
PDF المصدر (موثق) → خريطة التغطية → مهارة معرّفة → نشاط JSON → مدقّق Zod → فحص داخلي → صوت → حزمة منشورة
```

---

## 2. المراحل الستة

### المرحلة 1: مصدر موثق

| البند | الشرط |
|:---|:---|
| الشكل | PDF موثق من وزارة التربية الفلسطينية |
| الإصدار | سنة النشر مذكورة على الغلاف |
| الوضوح | يمكن قراءة المحتوى بصرياَ دون غموض |
| الحقوق | أنشطة أصلية (لا نسخ صفحات) |

**لا يُقبل أي نشاط بدون مصدر PDF موثق.**

### المرحلة 2: خريطة تغطية الصف

خريطة تغطي كل وحدة/درس في PDF وتحدّد:
- أي مهارات يمكن اشتقاقها
- أي أجزاء غير مناسبة (حقوق، محتوى حساس، تكرار)
- الأولوية حسب الأهمية التربوية

### المرحلة 3: تعريف المهارة

كل نشاط مرتبط بمهارة محددة:

```json
{
  "id": "g1.ar.letter.ba.recognize",
  "grade": 1,
  "subject": "arabic",
  "title": "تمييز حرف الباء في أول الكلمة",
  "prerequisites": ["g1.ar.letter.alef.identify"],
  "sourceRef": {
    "kind": "pack",
    "file": "Grade-1-Arabic.pdf",
    "unit": "وحدة حرف الباء",
    "page": 34,
    "edition": "2024"
  }
}
```

### المرحلة 5: المدقّق الآلي

شغّل أداة التدقيق:

```bash
npx vitest run tools/validate-packs.ts
```

المدقّق يفحص:
- **[Zod]** صحة هيكل JSON
- **[Linguistic]** جودة اللغة العربية (تشكيل، إملاء)
- **[Age-appropriate]** ملاءمة العمر (6–7 سنوات)
- **[Scaffolding]** وجود تلميحات مناسبة
- **[Source]** وجود source مفصّل
- **[Audio]** وجود بدائل نصية لكل صوت
- **[Accessibility]** تباين ألوان وصيغ نقر

**أي فشل = نشاط مرفوض ولا يدخل الحزمة.**

### المرحلة 6: الفحص الداخلي الموثق

| البند | من يفتش | المعيار |
|:---|:---|:---|
| الصحة التعليمية | مختص تربوي | يطابق الهدف المعرفي |
| اللغة والتشكيل | محرّر لغة | صحيح إملائياَ ومشكولاَ |
| الملاءمة العمرية | مختص نمو | مناسب لعمر 6–7 سنوات |
| جودة الصوت | مختص صوت | واضح، هادئ، مناسب |
| التلميح | مختص سقالات | يساعد لا يحل |

**كل نشاط يحتاج توقيع فحص داخلي موثق قبل النشر.**

## 3. إنتاج الصوت

### المواصفات التقنية

| المعيار | القيمة |
|:---|:---|
| الصيغة | Opus (.opus) أو Ogg (.ogg) |
| القنوات | Mono |
| معدل البت | 24 kbps |
| معدل العينة | 24000 Hz |
| القص التلقائي | فترات الصمت تُقص تلقائياَ |

### مكتبة الصوت المشتركة

بدلاَ من تسجيل كل تعليمات نشاط بشكل منفصل، نستخدم أصواتاً مشتركة تُكرَّر:

| النوع | العدد | المدة المتوسطة | الحجم التقديري |
|:---|:---|:---|:---|
| تعليمات نمطية (تُكرَّر) | ~60 | 4 ثوانٍ | ~720KB |
| حروف وتشكيل | ~84 | 2 ثوانٍ | ~500KB |
| بنك كلمات (كل كلمة) | ~600 | 1.5 ثوانٍ | ~2.7MB |
| تغذية راجعة (نجاح/重试) | ~40 | 3 ثوانٍ | ~360KB |
| **الإجمالي** | | | **~4.5MB (+25%)** |

### مقارنة TTS مقابل تسجيل بشري

| المعيار | TTS عربي | تسجيل بشري |
|:---|:---|:---|
| الجودة | مقبولة | ممتازة |
| التكلفة | صفر | 50–100$/ساعة |
| السرعة | فوري | أسبوع |
| الدقة التشكيلية | ضعيفة | ممتازة |
| القرار | يعتمد على قياس الجهاز المرجعي | يعتمد على قياس الجهاز المرجعي |

**الاختبار:** نسجّل عيّنة 10 أنشطة بكلا الطريقتين ونقيس على جهاز 2GB RAM.

## 4. بناء الحزمة (Pack Build)

```bash
# بناء حزمة صف أول عربي
npm run build:pack -- --grade=1 --subject=arabic

# البناء يشمل:
# 1. تجميع كل أنشطة الصف الأول العربي
# 2. تشغيل المدقّق على كل نشاط
# 3. ضغط الأصول (SVG + Opus)
# 4. إنتاج manifest.json
# 5. حساب الحجم الإجمالي
```

### محتوى الحزمة المنشورة

```
g1-ar-v1.0/
├── manifest.json
├── activities/
│   ├── g1.ar.letter.ba.match.01.json
│   ├── g1.ar.letter.ba.match.02.json
│   └── ...
├── audio/
│   ├── g1/ar/ba_q.opus
│   ├── g1/ar/success.opus
│   └── ...
├── svg/
│   ├── ba/door.svg
│   ├── ba/apple.svg
│   └── ...
└── skills.json
```

## 5. معدلات الإنتاج

### الحساب الواقعي

| البند | الوقت لكل نشاط |
|:---|:---|
| تأليف المحتوى | 15–30 دقيقة |
| رسم/إعداد SVG | 10–20 دقيقة |
| فحص داخلي | 5–10 دقيقة |
| تسجيل/توليد صوت | 5–15 دقيقة |
| **المجموع** | **35–75 دقيقة** |
| **بالمتوسط** | **~50 دقيقة** |

### بالعمالة المتواصلة (20 ساعة/أسبوع)

| الصف | الأنشطة | الساعات | الأشهر |
|:---|:---|:---|:---|
| 1 (عربي + إنجليزي) | ~264 | ~220 | 2.5–3 |
| 1 (رياضيات) | ~42 | ~35 | 0.5 |
| **الصف الأول كاملاً** | **~306** | **~255** | **3–4** |
| ستة صفوف كاملة | ~2,500 | ~2,000 | 24–30 |

**الاستنتاج:** الإنتاج الفردي ممكن للصف الأول في 3–4 أشهر. ستة صفوف تحتاج فريق.

## 6. صيانة المحتوى

عند تغيير منهج أو إصدار جديد:
1. يُحدّث مصدر PDF
2. تُعاد خريطة التغطية
3. تُفحص الأنشطة المتأثرة
4. يُصدّر ملف تحديث (`patch.json`)
5. يٌفعّل في التطبيق عبر التحديث المحلي
