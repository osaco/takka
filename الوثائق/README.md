# وثائق تكة — حزمة التخطيط الكاملة

الوثائق مرجع تخطيطي، وليست اعتماداً. الملف المرجعي الأول للمشروع يبقى `تكة.md` في جذر المستودع، وحالة العمل المعتمدة تبقى كما هي في `README.md` الجذري.

## ما لم يُرفع

سبعة ملفات PDF في `جديد تطبيق افكار/الاليات وطرق التعليم/` بقيت محلياً. السبب سياسة المستودع نفسها: `*.pdf` مستثنى في `.gitignore`، و`.gitattributes` يوجّه ملفات PDF إلى Git LFS، و`README.md` الجذري ينص على إبقاء ملفات PDF خارج GitHub. رفعها لاحقاً ممكن عبر LFS بقرار من المالك.
