## 🚀 منهجية Vibe Coding للمشروع

### المبدأ
نبدأ من **النواة الصلبة** (domain/engine) ثم نضيف طبقات واحدة تلو الأخرى. كل طبقة تُختبر قبل الانتقال للتالية.

### قاعدة البناء
```
1. اكتب domain/nice (بدون React) أولاً
2. اكتب الاختبارات وتأكد أنها تمرّ
3. ابنِ layer التالٍ فوق الـ domain
4. كرّر
```

### قاعدة المحتوى
```
1. لا يُبنى قالب إلا بعد وجود 10 أنشطة حقيقية تحتاجه
2. كل نشاط JSON يجب أن يملك source موثّق
3. لا يُحمّل نشاط إلا بعد مروره على مدقّق Zod
```
