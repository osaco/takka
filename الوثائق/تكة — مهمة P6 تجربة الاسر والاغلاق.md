# 🟤 P6 — تجربة أسر + إطلاق MVP
> **المدة:** أسبوعان  
> **البوابة:** P5 مفتوحة  
> **القاعدة:** موافقة ولي أمر + خطة خصوصية

---

## 🎯 الأهداف

1. توزيع APK على 5-10 أسر غزية (عينة صغيرة)
2. جمع ملاحظات عن: السهولة، الفهم، المتعة، الأمان العاطفي
3. كتابة تقرير تجربة الأسرة
4. تحسينات نهائية بناءً على الملاحظات
5. الإصدار الأول (v0.1.0)

---

## 📋 checklist ما قبل الإطلاق

### ✅ المحتوى
- [ ] 20+ نشاط حقيقي منشور
- [ ] كل نشاط يملك source موثّق + audit.status
- [ ] خريطة الصف الأولى مكتملة
- [ ] تغطية ≠ ادعاء "المنهاج الكامل"

### ✅ الأداء
- [ ] FPS ≥ 30 على جهاز 2GB RAM
- [ ] فتح < 3 ثوانٍ
- [ ] ذاكرة ≤ 120MB
- [ ] APK ≤ 28MB

### ✅ الخصوصية والأمان
- [ ] لا هوية شخصية
- [ ] لا ميكروفون
- [ ] لا إنترنت مطلوب
- [ ] لا تتبع
- [ ] تصدير/استيراد JSON يعمل

### ✅ الجودة التربوية
- [ ] أمان الخطأ (لا أحمر صارخ)
- [ ] السقالات الأربع تعمل
- [ ] قاعدة الإتقان: 3 مستقل + جلستين + يوم
- [ ] الانحدار 21 يوم يعمل

### ✅ الإتاحة
- [ ] Tajawal خط معتمد
- [ ] تشكيل عربي واضح
- [ ] RTL صحيح
- [ ] touches targets ≥ 56dp
- [ ] prefers-reduced-motion يعمل

## 📝 خطة التجربة الأسرية

### المرحلة أ: التحضير (3 أيام)
1. بناء APK نهائي (v0.1.0)
2. كتابة ورقة موافقة أولياء الأمور (شرح الخصوصية)
3. اختيار 5-10 عائلات مع أطفال في الصف الأول
4. توزيع APK عبر USB أو واتساب

### المرحلة ب: التشغيل (7 أيام)
1. كل أسرة تستخدم التطبيق يومياً لمدة 7 أيام
2. سجل ملاحظات أسبوعي (ما أحبّوه / ما كرهوه)
3. مقابلة قصيرة (5 دقائق) مع كل ولي أمر
4. قياس: كم جلسة في اليوم؟ كم نشاط؟ كم دقيقة؟

### المرحلة ج: التحليل (3 أيام)
1. تجميع الملاحظات
2. تصنيف المشاكل: حرج / مهم / ثانوي
3. كتابة تقرير التجربة
4. تحديد أولويات التحسين

### المرحلة د: التحسين (3 أيام)
1. إصلاح المشاكل الحرجة
2. تحسين الملاحظات المهمة
3. إصدار v0.1.1

## 📊 مقاييس النجاح بعد التجربة

| المقياس | الهدف | كيفية القياس |
|:---|:---|:---|
| نسبة الأطفال الذين يعودون يوماً تلو الآخر | ≥ 60% | عدد الأيام النشطة ÷ أيام الاستخدام |
| متوسط مدة الجلسة | 4–8 دقائق | SessionRecord.durationMs |
| نسبة إتمام النشاط الأول بدون مساعدة | ≥ 70% | Evidence kind = independent |
| نسبة طلب التلميح | 15–30% | Evidence with_hint + with_scaffold |
| رضا ولي الأمر (سؤال: "هل يكرر الطفل استخدام التطبيق؟") | ≥ 70% نعم | مقابلة مباشرة |
| بلاغات خطأ تقنية | ≤ 5 بلاغات | تقرير من التطبيق |

## 🚀 خطوات الإطلاق

### الخطوة 1: Tag الإصدار
```bash
git tag v0.1.0
git push origin v0.1.0
```

### الخطوة 2: بناء APK نهائي
```bash
pnpm build
pnpm capacitor:sync
cd android && ./gradlew assembleDebug
```

### الخطوة 3: اختبار final
- [ ] تثبيت على 3 أجهزة مختلفة (2GB, 4GB, 8GB RAM)
- [ ] اختبار جميع الشاشات
- [ ] اختبار جميع القوالب
- [ ] اختبار تصدير/استيراد
- [ ] اختبار الوضع المنخفض

### الخطوة 4: توثيق
- README.md شامل
- دليل الاستخدام لولي الأمر
- وثيقة الخصوصية
- changelog v0.1.0

### الخطوة 5: توزيع
- Google Play (إذا توفر)
- أو توزيع مباشر عبر واتساب/USB
- أو GitHub Releases
