## 1. `island/state.ts` — حالة الجزيرة

```ts
// المدخلات: لا شيء (قيمة ابتدائية)
// المخرجات: IslandState
// الثوابت: شبكة 12x12 حتمية · hqLevel ∈ {1,2,3} · فتح الأرض مرتبط بالترقية
IslandState = {
  phase: 'single-island',
  hqLevel: 1 | 2 | 3,
  unlockedLand: 10 | 12
}
```

Zod Schema:
```ts
IslandStateSchema = z.object({
  phase: z.literal('single-island'),
  hqLevel: z.union([z.literal(1), z.literal(2), z.literal(3)]),

```

الثوابت والقواعد:
- الترقية دالة نقية تتحقق من الحالة الحالية قبل التعديل، وتُرجع حالة جديدة غير قابلة للتعديل (immutable) أو خطأ نوعي صريح — لا `null` ولا صمت.
- ترقية HQ3 لا تجوز قبل إكمال وتثبيت HQ2.

## 2. `island/economy.ts` — الاقتصاد وحراسة الموارد

```ts
// المدخلات: EconomyState + فعل واحد {grantFirstMastery | grantReview | spend}
// المخرجات: EconomyState (immutable) أو خطأ نوعي صريح
// الثوابت: كل الموارد ≥ 0 · سقف كل مورد 9999 · مراجعة اليوم ≤ 6 · أول إتقان مرة واحدة
EconomyState = {
  stars: number,
  wood: number,
  stone: number,
  crystal: number,
  masteredSkills: SkillId[],
  dailyReview: { count: number /* 0..6 */, dayKey: string }
}
```

الثوابت والقواعد:
- `grantFirstMastery(state, skillId)`: إذا كانت المهارة مسجلة مسبقاً يعيد نفس الحالة حرفياً (Idempotent). وإلا: +10 نجوم +3 مواد (1 خشب / 1 حجر / 1 بلورة) + تسجيل المهارة.
- `grantReview(state, dayKey)`: إذا كانت العدّة أقل من 6 واليوم نفسه: +3 نجوم +1 للعدّة. وإذا تغيّر اليوم (dayKey مختلف): تصفير العدّة أولاً والبدء من 1.
- `spend(cost)`: لا يُنفذ إن لم تكفِ الموارد بالكامل (خصم ذري دفعة واحدة)، ولا يقبل قيماً سالبة.
- حصيلة الجزيرة المتوقعة: إجمالي الدخل المكتسب عند إكمال جميع المهارات والحصاد والمراجعات ≥ تكلفة إكمال ترقيات الجزيرة بفائض أمان ~19%.

## 3. `island/upgrade-table.ts` — جدول الترقيات الحتمي

```ts
// المدخلات: BuildingId + المستوى الحالي
// المخرجات: UpgradeSpec {cost, masteryGate?, opens: BuildingId[]}
// الثوابت: دالة حتمية نقية، لا عشوائية، ولكل كلفة مبرر موثق
UpgradeTable: Record<BuildingId, Record<1|2|3, UpgradeSpec>>
```

الثوابت والقواعد:
- كل ترقية تتطلب كلفة واضحة، وترتبط باحتكاك إتقان صريح (`masteryGate`) للمباني التخصصية.
- HQ2 و HQ3 هما ترقيات برج تكة المركزي إلى مستويي 2 و 3.
- جدول الكشف التدريجي مشتق حتمياً من هذا الجدول عبر دالة نقية `revealedBuildings(hqLevel)`، منعاً للازدواجية.

## 4. `island/companions.ts` — الرفاق وشروط الفتح

```ts
// المدخلات: MasteryState + IslandState
// المخرجات: CompanionState
// الثوابت: فطين مفتوح دائماً كرفيق افتراضي · الفتح دالة متسلسلة حتمية
```

الثوابت والقواعد:
- `tryUnlockCompanion(state, id)`: يفحص حالة الرفيق، يتحقق من الشرط، ويفتح الرفيق مرة واحدة فقط (Idempotent).
- إذا تحققت شروط رفيقين في نفس الجلسة، يُعالج الفتح بتتابع تسلسلي يمنع تعارض الحالة (Race condition).
- شروط الفتح مبنية فقط على إتقان مهارات حقيقية ومستوى الجزيرة؛ لا مكافآت عشوائية ولا فتح زمني غير مبرر.

## 5. `island/placement.ts` — مواضع المباني على الشبكة

```ts
// المدخلات: 9 إدخالات {buildingId, x, y}
// المخرجات: PlacementState | خطأ هادئ مع Fallback
// الثوابت: الإحداثيات ضمن 0..11 · لا تداخل بين مبنيين · buildingId من الكتالوج المعتمد
```

الثوابت والقواعد:
- الحفظ محلي في Dexie تحت مفتاح الملف الرمزي للطفل — بلا استيراد/تصدير خارجي في هذه المرحلة.
- عند فشل التحقق أو تلف بيانات الموضع: الرجوع التلقائي إلى التوزيع الافتراضي الآمن (برج تكة بالمركز) مع تسجيل تحذير دون كسر الواجهة.
- نقل مبنى ينجح فقط إذا كان الموضع الجديد شاغراً وضمن حدود الشبكة المسموحة لمستوى الجزيرة الحالي.

## 6. `island/mission-link.ts` — ربط المبنى بالمهارات والحزم

```ts
// المدخلات: BuildingId + كتالوج الحزم المعتمدة
// المخرجات: {packId, skillIds[]}
// الثوابت: فشل صارم عند أي مهارة غير موجودة في الحزمة المعتمدة
```

الثوابت والقواعد:
- الجدول لا يعيد تكرار محتوى يدوي؛ بل يشير حصراً إلى معرفات المهارات `skillIds` في الحزم المعتمدة (g1-ar, g1-math).
- التحقق أثناء التحميل (Validation on pack load): إذا أشارت مهمة إلى مهارة غير معرّفة يُطلق خطأ فوري في بيئة التطوير ويسجل تحذيراً آمناً في الإنتاج.
- الجلسة تستخدم المهارات الناتجة مع محرك الجلسات `session/builder` القائم بدون تعديل على منطق التعلم التفاعلي.
