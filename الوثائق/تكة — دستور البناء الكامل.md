# 🏛️ دستور بناء تطبيق «تكة» — النسخة النهائية

> **الإصدار:** 3.0 — 20 تشرين الأول 2026  
> **الحالة:** دستور تنفيذي نهائي  
> **مدة البناء المتوقعة:** 8–10 أسابيع من العمل الفعلي  
> **المبدأ الحاكم:** المحرك أولًا ← المدقّق ثانيًا ← الشاشة ثالثًا

---

## 📜 القسم الأول: هوية المشروع

### ما هو تكة
تطبيق تعليمي ترفيهي عربي، أوفلاين 100%، لأطفال غزة الصفوف 1–6. في المرحلة الأولى: **الصف الأول** فقط + **العربية والرياضيات** فقط.

### ما ليس هو
ليس بنك أسئلة · ليس نسخة رقمية من الكتاب المدرسي · ليس لعبة مكافآت يفصلها درس · ليس ادعاء "المنهاج الكامل".

### الوعد المزدوج
| للطفل | للأسرة |
|:---|:---|
| تعلّم باكتشاف · خطأ بلا خوف · تلميح بلا تأنيب · خروج متى شاء بلا خسارة | محتوى موثق المصدر · تغطية معلنة بصدق · تقدّم وصفي · لا إعلانات · لا بيانات شخصية |

### القيود الحاكمة (غزة أولاً)
انقطاع كهرباء متقطع · إنترنت شبه معدوم · هواتف 2GB RAM وشاشات متضرّرة · انقطاع طويل عن الدراسة · صدمات تحتاج بيئة آمنة لا ممتحناً.

## 📐 القسم الثاني: المكدس التقني (قرار نهائي)

| الطبقة | الاختيار | الدور الدقيق | الحدّ الذي لا يتجاوزه |
|:---|:---|:---|:---|
| الواجهات | **React 18/19** | الشاشات، النصوص العربية، RTL، النماذج، بوابة ولي الأمر | لا يدير حلقة رسم ولا حركة إطارية |
| المنطق | **TypeScript** (strict) | محرك الإتقان، التدرج، التقييم، التحقق من المحتوى، التخزين | لا يستورد React ولا DOM ولا Canvas |
| العالم | **Canvas 2.5D** | الأرخبيل، الجزر، حالة الإزهار، التنقل البصري | لا نصوص عربية داخله؛ لا أكثر من 120 عنصراً متحركاً |
| الألعاب | **Phaser** (مؤجّل) | ألعاب تحتاج مشهداً وفيزياء وتصادماً | يُحمّل بـ `dynamic import` عند فتح اللعبة فقط |
| 3D | **Three.js — مؤجّل** | لا شيء حالياً | لا يدخل حزمة الإصدار الأول |
| البناء | **Vite** | تجميع، تقسيم حزم لكل جزيرة/لعبة | — |
| الحالة | **Zustand** | حالة الجلسة والعالم والملف النشط | لا تُخزَّن فيه بيانات المنهاج |
| التحقق | **Zod** | مصادقة JSON المحتوى عند البناء وعند التحميل | — |
| التخزين | **Dexie (IndexedDB)** | التقدم، المحاولات، البلاغات، الإعدادات | لا يُستدعى من مكوّن React مباشرة |
| الصوت | **Howler / Web Audio** | التعليمات، التغذية الراجعة، مؤثرات ناعمة | لا تشغيل تلقائي؛ لا صوت إلزامي |
| الغلاف | **Capacitor 6** | APK، نظام الملفات الدائم، الاهتزاز الخفيف | لا صلاحيات زائدة |
| الاختبار | **Vitest** | محرك الإتقان، التدرج، الحفظ، التحقق | لا اختبارات UI شاملة في المرحلة الأولى |

## 🎯 القسم الرابع: محرك الإتقان — القرار الحاكم

> **المهارة تُعدّ «متقنة» إذا ظهرت مستقلةً ثلاث مرات، في جلستين مختلفتين على الأقل، وبفاصل زمني لا يقل عن يوم، دون تلميح.**

### حالات المهارة
- `not_reached` — لم يصل إليها بعد
- `tried` — جرّب
- `with_help` — أكمل بمساعدة
- `independent` — أظهر إتقاناَ مستقلاً

### السقالات — أربع درجات تتلاشى
| الدرجة | ما يحدث | متى تُستخدم |
|:---|:---|:---|
| 1. نمذجة كاملة | الرفيق «فطين» يحل الخطوة الأولى أمام الطفل | أول لقاء بمهارة |
| 2. توجيه بصري | إبراز العنصر الصحيح، سهم، وميض هادئ | بعد خطأ واحد |
| 3. تلميح نصي/صوتي | جملة واحدة تقول الخطوة التالية لا الجواب | بعد خطأين |
| 4. تبسيط المهمة | نفس المهارة بمثال أسهل أو خيارات أقل | بعد ثلاث محاولات |

**قاعدة:** لا نمنع المحاولة، ولا ننقص شيئاً، ولا نُظهر «فشلاً».

## 🚫 القسم السادس: حدود غير قابلة للتفاوض

| القاعدة | التفصيل |
|:---|:---|
| لا هوية | لا اسم حقيقي، لا هاتف، لا بريد، لا موقع، لا صورة، لا صوت طفل |
| لا ميكروفون | في الـMVP ولا في أي إصدار قريب |
| لا شبكة في الجوهر | التعلم والتقدم يعملان كاملاً دون اتصال |
| لا تتبع | لا تحليلات، لا إرسال أحداث، لا معرّفات إعلانية |
| لا دفع للطفل | لا شاشة شراء في رحلة الطفل، ولا إشارة إلى سعر |
| لا إدمان | لا سلاسل عقابية، لا صناديق حظ، لا مؤقت ضغط، لا تمرير لا نهائي |
| لا لوم | لا أحمر صارخ، لا صوت خطأ، لا «خسرت»، لا مقارنة بأطفال آخرين |

## 🛑 القسم العاشر: التوقّفات الإلزامية

1. **توقّف عن توسيع القوالب** قبل أن يوجد محتوى حقيقي يستخدمها.
2. **توقّف عن التخطيط لستة صفوف** قبل اعتماد الصف الأول كاملاً.
3. **توقّف عن وصف التطبيق بأنه «المنهاج الفلسطيني»** — سمّه: «مسار رزم غزة المتاحة للصف الأول».
4. **لا تكتب سوى سطر كود واحد** حتى يتم حسم النظام البصري الموحّد وخريطة الصف الأولى.
