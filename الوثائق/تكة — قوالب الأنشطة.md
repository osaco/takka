## 2. قالب 1: سحب ومطابقة (Drag & Match)

### الوصف
سحب عنصر من مجموعة وأفلاته على عنصر مطابق.

### بنية JSON

```json
{
  "template": "drag_match",
  "config": {
    "prompt": "اسحب الصورة إلى الحرف المناسب",
    "pairs": [
      {
        "draggable": { "id": "d1", "label": "بَاب", "image": "svg/ba/door.svg" },
        "target": { "id": "t1", "label": "بَ", "char": "بَ" }
      },
      {
        "draggable": { "id": "d2", "label": "تُفَّاح", "image": "svg/ba/apple.svg" },
        "target": { "id": "t2", "label": "تُ", "char": "تُ" }
      }
    ],
    "shuffleTargets": true
  }
}
```

### مكونات React

```
DragMatchGame/
├── DragMatchGame.tsx    # المكون الرئيسي
├── hooks.ts             # useDragMatch (إدارة السحب والإفلات)
├── DragItem.tsx         # عنصر قابل للسحب
├── DropTarget.tsx       # هدف الإفلات
└── styles.css
```

### قواعد التصميم
- عنصر قابل للسحب: ≥ 56dp
- منطقة الإفلات: ≥ 56dp
- feedback بصري فوري عند الإفلات (لون أخضر/برتقالي)
- لا صوت خطأ — فقط wiggle لطيف

## 3. قالب 2: تتبع مسارات (Trace Path)

### الوصف
رسم حرف أو رقم بتتبع مسار مرسوم.

### بنية JSON

```json
{
  "template": "trace_path",
  "config": {
    "prompt": "تتبّع الحرف لتكمل الكتابة",
    "character": "بَ",
    "strokePath": "M 50,100 L 150,100 L 150,200 L 50,200 Z",
    "guideOpacity": 0.3,
    "snapToPath": true,
    "minStrokeLength": 80
  }
}
```

### المكونات
```
TracePathGame/
├── TracePathGame.tsx
├── hooks.ts
├── StrokeCanvas.tsx    # Canvas 2D للرسم
└── styles.css
```

### ملاحظة تقنية
هذا القالب يحتاج Canvas 2D داخل React (ليس عالم Canvas الرئيسي).

## 4. قالب 3: استماع وتمييز (Listen & Identify)

### الوصف
الطفل يسمع صوتاً/كلمة ويختار الصورة أو الحرف المناسب.

### بنية JSON

```json
{
  "template": "listen_identify",
  "config": {
    "prompt": "استمع واختر ما تسمع",
    "audioFile": "audio/g1/ar/ba_q.opus",
    "options": [
      { "id": "a", "label": "ألف", "image": "svg/alef.svg", "correct": false },
      { "id": "b", "label": "باء", "image": "svg/ba.svg", "correct": true },
      { "id": "c", "label": "تاء", "image": "svg/ta.svg", "correct": false }
    ]
  }
}
```

### المكونات
```
ListenIdentifyGame/
├── ListenIdentifyGame.tsx
├── hooks.ts
└── styles.css
```

### قواعد الصوت
- زر تشغيل صوت كبير (≥ 56dp)
- إعادة التشغيل متاحة
- نص替代 موجود دائماً

## 5. قالب 4: ميزان مبسّط (Balance) — للرياضيات

### الوصف
وضع أوزان على طرفي ميزان لتوازن المعادلة.

### بنية JSON

```json
{
  "template": "balance",
  "config": {
    "prompt": "وازن الميزان بجعل الطرفين متساويين",
    "leftSide": {
      "items": [{ "value": 3, "label": "3" }],
      "total": 3
    },
    "rightSide": {
      "items": [],
      "total": 0,
      "options": [
        { "id": "a", "value": 1, "label": "1" },
        { "id": "b", "value": 2, "label": "2" },
        { "id": "c", "value": 3, "label": "3" }
      ]
    },
    "correctAnswer": "c"
  }
}
```

### ملاحظة
هذا القالب يمكن بناؤه بـ SVG/DOM دون Phaser. Phaser مطلوب فقط إذا احتجنا فيزياء حقيقية (توازن معقد).
