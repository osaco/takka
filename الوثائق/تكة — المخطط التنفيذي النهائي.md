# 🧭 المخطط التنفيذي النهائي — «تكة» (Takka)

> **الإصدار:** 2.0 — 20 تشرين الأول 2026  
> **الحالة:** جاهز للتنفيذ الفوري  
> **يعتمد:** الوثيقة 10 (الرؤية النهائية) + كانفس المشروع (11) + أسس رؤية المشروع (00-09)  
> **الغرض:** وثيقة واحدة تُلخّص كل ما نحتاجه لبناء تكة — من القرار المعماري إلى خطة الإنتاج والمواعيد النهائية.

## 0. ملخص تنفيذي

| البند | القرار |
|:---|:---|
| **ما هو تكة** | تطبيق تعليمي ترفيهي عربي، أساسي أوفلاين، لأطفال غزة الصفوف 1–6. يركّز على الصف الأول ومادتين (العربية + الرياضيات) في المرحلة الأولى. |
| **المكدس التقني** | React 18/19 + TypeScript + Canvas 2.5D + Zustand + Dexie.js + Zod + Howler.js + Capacitor 6 + Vitest |
| **القوالب الأولية** | 3 قوالب فقط (سحب+مطابقة، تتبع، استماع+تمييز) + ميزان مبسّط للرياضيات |
| **النطاق MVP** | صف واحد + العربية + الرياضيات = ~70 درسًا ≈ ~420 نشاطًا (أولوية) |
| **سقف الحجم** | ≤ 25MB للـMVP (حزمة الصف الأول فقط) |
| **مبدأ البناء** | المحرك أولًا ← المدقّق ثانيًا ← الشاشة ثالثًا. لا جمال لمحتوى غير قابل للتحقق. |
| **أهم قرار فوري** | اعتماد النظام البصري الموحّد (DESIGN.md) + خريطة الصف الأولى قبل أي كود. |

## 1. الرؤية والرسالة

### ما هو تكة
تكة محرك إتقان (Mastery Engine) بواجهة عالم كرتوني. الطفل يكتشف، يخطئ بلا خوف، ويتوقف متى شاء — عالمه يُرمَّم مع كل مهارة يتقنها.

### ما ليس هو
ليس بنك أسئلة · ليس نسخة رقمية من الكتاب المدرسي · ليس لعبة مكافآت يفصلها درس · ليس ادعاء "المنهاج الكامل".

### الوعد المزدوج
| للطفل | للأسرة |
|:---|:---|
| تعلّم باكتشاف · خطأ بلا خوف · تلميح بلا تأنيب · خروج متى شاء بلا خسارة | محتوى موثق المصدر · تغطية معلنة بصدق · تقدّم وصفي · لا إعلانات · لا بيانات شخصية |

### القيود الحاكمة (غزة أولاً)
انقطاع كهرباء متقطع · إنترنت شبه معدوم · هواتف 2GB RAM وشاشات متضرّرة · انقطاع طويل عن الدراسة · صدمات تحتاج بيئة آمنة لا ممتحناً.

## 3. المكدس التقني النهائي (قرار نهائي)

| الطبقة | الاختيار | الدور الدقيق | الحدّ الذي لا يتجاوزه | متى نعيد النظر |
|:---|:---|:---|:---|:---|
| الواجهات | **React 18/19** | الشاشات، النصوص العربية، RTL، النماذج، بوابة ولي الأمر | لا يدير حلقة رسم ولا حركة إطارية | إذا زادت إعادة الرسم في الأنشطة عن 30% من الإطارات |
| المنطق | **TypeScript** (strict) | محرك الإتقان، التدرج، التقييم، التحقق من المحتوى، التخزين | لا يستورد React ولا DOM ولا Canvas | لا |
| العالم | **Canvas 2.5D الحالي** | الأرخبيل، الجزر، حالة الإزهار، التنقل البصري | لا نصوص عربية داخله؛ لا ظلال ديناميكية في الحلقة؛ لا أكثر من 120 عنصراً متحركاً | إذا احتجنا تصادم/فيزياء/مشاهد متعددة → Phaser |
| الألعاب | **Phaser** (عند الطلب) | ألعاب تحتاج مشهداً وفيزياء وتصادم وحركة كائنات | يُحمّل بـ `dynamic import` عند فتح اللعبة فقط | إذا لم يتجاوز أي نشاط حاجة DOM/SVG فلا يضاف أصلاً |
| 3D | **Three.js — مؤجّل** | لا شيء حالياً | لا يدخل حزمة الإصدار الأول | إذا ثبت أن 2.5D لا يحقق «الإحساس بالعالم» في اختبار أسر |
| البناء | **Vite** | تجميع، تقسيم حزم لكل جزيرة/لعبة | — | — |
| الحالة | **Zustand** | حالة الجلسة والعالم والملف النشط | لا تُخزَّن فيه بيانات المنهاج | — |
| التحقق | **Zod** | مصادقة JSON المحتوى عند البناء وعند التحميل | — | — |
| التخزين | **Dexie (IndexedDB)** عبر مستودع مجرّد | التقدم، المحاولات، البلاغات، الإعدادات | لا يُستدعى من مكوّن React مباشرة | إذا أثبت القياس أن SQLite أنسب على أندرويد |
| الصوت | **Howler / Web Audio** | التعليمات، التغذية الراجعة، مؤثرات ناعمة | لا تشغيل تلقائي؛ لا صوت إلزامي | حسب نتيجة مقارنة TTS/تسجيلات |
| الغلاف | **Capacitor 6** | APK، نظام الملفات الدائم، الاهتزاز الخفيف | لا صلاحيات زائدة | — |
| الاختبار | **Vitest** | محرك الإتقان، التدرج، الحفظ، التحقق | لا اختبارات UI شاملة في المرحلة الأولى | — |

### لماذا Canvas 2.5D وليس Three.js؟

| المعيار | Canvas 2.5D | Three.js 3D |
|:---|:---|:---|
| الحجم | ~0 (كود فقط) | ~600KB gzip + مجسمات + خامات |
| الذاكرة | عشرات الميغابايت | 100MB+ على أجهزة ضعيفة |
| البطارية | رسم 2D مع ظلال مسبقة | رسم WebGL مستمر |
| خط الأنابيب | لا يحتاج Blender/gltfpack/KTX2 | يحتاج سلسلة أدوات كاملة |
| النصوص العربية | DOM فوقه (مثالي) | DOM فوقه (ممكن لكنه غريب) |
| الإحساس المطلوب | «جزر عائمة دافئة تُرمَّم» ✅ | زائد على الحاجة |

## 5. قلب المشروع: محرك الإتقان

### الكيانات الأساسية

```typescript
type Grade = 1 | 2 | 3 | 4 | 5 | 6;
type SubjectId = 'arabic' | 'math' | 'english' | 'civic' | 'science';

interface Skill {
  id: string;                    // "g1.ar.letter.ba.recognize"
  grade: Grade;
  subject: SubjectId;
  title: string;
  prerequisites: string[];       // مهارات سابقة
  sourceRef: SourceRef;          // مصدر موثق أو وسم "تأسيس أصلي"
}

interface SourceRef {
  kind: 'pack' | 'curriculum-index' | 'foundational';
  file?: string;
  page?: number;
  unit?: string;
  edition?: string;
}

type EvidenceKind = 'independent' | 'with_hint' | 'with_scaffold' | 'exposed_only';

interface Evidence {
  skillId: string;
  at: number;                    // epoch ms
  kind: EvidenceKind;
  templateId: string;
  itemId: string;
  attempts: number;
  durationMs: number;
}

type SkillState =
  | 'not_reached'    // لم يصل إليها بعد
  | 'tried'          // جرّب
  | 'with_help'      // أكمل بمساعدة
  | 'independent';   // أظهر إتقاناً مستقلاً
```

### قاعدة الإتقان **[قرار]**

> **المهارة تٌعدّ «مُتقنة» إذا ظهرت مستقلةً ثلاث مرات، في جلستين مختلفتين على الأقل، وبفاصل زمني لا يقل عن يوم، دون تلميح.**

- **«جرّب»**: تفاعل وغادر قبل خطوة التحقق.
- **«أكمل بمساعدة»**: نجح بعد تلميح أو سقالة أو إعادة محاولة.
- **«أظهر إتقاناَ مستقلاً»**: نجح في تحقق بلا مساعدة.
- **الانحدار (Decay)**: إذا مرّ 21 يوماً بلا دليل مستقل، تعود المهارة إلى «تحتاج مراجعة» في الاقتراح فقط — **ولا تُلغى من سجل الطفل أبداً**، ولا تُعرض كخسارة.

### السقالات — أربع درجات تتلاشى

| الدرجة | ما يحدث | متى تٌستخدم |
|:---|:---|:---|
| 1. نمذجة كاملة | الرفيق «فطين» يحل الخطوة الأولى أمام الطفل | أول لقاء بمهارة |
| 2. توجيه بصري | إبراز العنصر الصحيح، سهم، وميض هادئ | بعد خطأ واحد |
| 3. تلميح نصي/صوتي | جملة واحدة تقول الخطوة التالية لا الجواب | بعد خطأين |
| 4. تبسيط المهمة | نفس المهارة بمثال أسهل أو خيارات أقل | بعد ثلاث محاولات |

**قاعدة:** لا نمنع المحاولة، ولا ننقص شيئاَ، ولا نُظهر «فشلاً». عند الدرجة 4 نقترح **جسراً تأسيسياً** اختيارياً، لا نفرضه.

## 6. وحدة الجلسة: «تكة واحدة» متغيرة الطول

| الصف | طول «تكة» | المراحل المضمنة | عدد التفاعلات |
|:---|:---|:---|:---|
| 1–2 | **4–6 دقائق** | تنشيط ← نمذجة ← ممارسة موجهة ← تحقق ← احتفال | 3–5 |
| 3–4 | **7–10 دقائق** | + جولة طلاقة قصيرة ← نقل الأثر | 6–9 |
| 5–6 | **11–15 دقيقة** | الدورة الثمانية كاملة | 10–14 |

**القاعدة:** الطفل ينهي «تكة» كاملة في جلسة واحدة، ويستطيع الخروج في أي لحظة. لا تٌقطع الجلسة على الطفل، ولا تٌمدّد قسراً.

### الدورة المُضغطة للصفوف 1–2

| # | المرحلة | الصفوف 1–2 | الصفوف 3–4 | الصفوف 5–6 |
|:---|:---|:---|:---|:---|
| 1 | تنشيط معرفة سابقة | سؤال واحد بصري | سؤالان | سؤالان + تبرير |
| 2 | نمذجة صريحة | مثال محسوس فقط | محسوس ← شبه محسوس | محسوس ← رمز |
| 3 | ممارسة موجهة | خطوة واحدة | خطوتان | خطوتان + تفسير |
| 4 | جولة طلاقة | ❌ تٌدمج | 60–90 ثانية | 90–120 ثانية |
| 5 | نقل الأثر في الجزيرة | ❌ | ✅ | ✅ |
| 6 | تحقق مستقل | ✅ واحد | ✅ | ✅ + «كيف عرفت؟» |
| 7 | تفرّع وتغذية راجعة | تلقائي هادئ | تلقائي | تلقائي + سؤال تأملي |
| 8 | إغلاق آمن | ✅ | ✅ | ✅ |

## 7. العالم: عقد Canvas 2.5D

### ما يملكه الكانفس وما يملكه DOM

| الكانفس يملك | DOM يملك |
|:---|:---|
| البحر، السحب، الجزر، الطرق، المنارات | كل نص عربي (عناوين، أسماء، أرقام) |
| حالة الإزهار، الفتح، الضباب | الأزرار، البطاقات، التلميحات، الحوارات |
| الحركة الخفيفة (موج، طيور، جزيئات) | شريط الحالة، زر الصوت، زر الخروج |
| الالتقاط (Hit-testing) على الجزر | إمكانية الوصول، التركيز، قارئ الشاشة |

### حالات الجزيرة

```
ساكنة (Sleeping) ← صحوة/ترميم (Awakening) ← إزهار (Blooming)
```

- **ساكنة**: ضباب خفيف وألوان هادئة
- **صحوة**: طرق تٌفتح وماء يجري
- **إزهار**: شارة ذهبية واحتفال هادئ

**قاعدة:** الحالة تُحسب من بيانات الإتقان، ولا تُخزّن كحقل مستقل. مصدر حقيقة واحد = لا تناقض.

### الوضع المنخفض (Degraded Mode)

يُفعّل تلقائياً عند أي من: `deviceMemory < 2GB`، أو `hardwareConcurrency ≤ 4`، أو متوسط إطار > 25ms لثلاث ثوانٍ.
في الوضع المنخفض: خريطة شبه ثابتة، بلا موج ولا جزيئات، وحركات انتقال قصيرة.

### ميزانية الأداء

| البند | السقف | كيف يُقاس |
|:---|:---|:---|
| إطارات | 60fps هدف، 30fps حد أدنى | `requestAnimationFrame` + متوسط متحرك |
| عناصر متحركة | ≤ 120 | عدّاد في وضع التطوير |
| عمليات رسم/إطار | ≤ 400 | تتبّع يدوي |
| DPR | ≤ 2 | قصّ عند الإقلاع |
| ذاكرة التطبيق | ≤ 120MB | Android Profiler |
| زمن الفتح البارد | < 3 ثوانٍ | قياس على جهاز فعلي |
| حزمة JS الأولية | ≤ 450KB gzip | `vite build` |

## 8. المحتوى: خط الأنابيب وعقد النشاط

### خط الأنابيب

```
مصدر موثق (PDF + صفحة/وحدة)
    ↓
خريطة تغطية الصف
    ↓
مهارة معرّفة + متطلبات سابقة
    ↓
نشاط أصلي بصيغة JSON
    ↓
مدقّق Zod + مدقّق تربوي آلي
    ↓
فحص داخلي موثق: صحة، لغة، تشكيل، عمر، تلميح
    ↓
صوت اختياري + بديل نصي
    ↓
حزمة منشورة: صف + مادة + إصدار
    ↓
التطبيق: تحميل محلي
```

**قاعدة:** أي نشاط لا يملك `source` أو `audit.status` لا يٌبنى ولا يٌحمّل. المدقّق يفشل البناء، لا يُحذّر فقط.

| البند | الصف الأول | ستة صفوف |

## 12. التخزين والنسخ الاحتياطي

### المستودع المجرّد

```typescript
interface ProgressRepository {
  loadProfile(profileId: string): Promise<Profile | null>;
  saveEvidence(e: Evidence): Promise<void>;         // كتابة ذرية
  saveSession(s: SessionRecord): Promise<void>;
  getSkillStates(profileId: string): Promise<Record<string, SkillState>>;
  exportProfile(profileId: string): Promise<Blob>;  // JSON
  importProfile(file: Blob): Promise<Profile>;
}
```

- **Dexie** اليوم، **SQLite** خيار لاحق خلف نفس الواجهة.
- **كتابة ذرية**: كل تغيير حالة يٌكتب في معاملة واحدة.
- **طلب تخزين دائم** عند أول إقلاع (`navigator.storage.persist()`).
- **تحذير مساحة صادق** لولي الأمر قبل أي حذف.

### تصدير/استيراد التقدم **[قرار مهم]**

> ملف تقدم واحد (JSON) يُصدَّر إلى مجلد التنزيلات أو يُشارك عبر تطبيق الملفات، ويُستورد لاحقاً.
> لا حساب، لا سحابة، لا شبكة.
> يحتوي: معرّف الملف الرمزي، الصف، الحالات، الأدلة، الإصدار.
> يُوقّع بمجموع تحقق بسيط لمنع الاستيراد التالف.
> **تكلفة التنفيذ: يومان**، وتغلق سؤالاَ مفتوحاً منذ إصدار الدستور.

## 13. قرار الحزمة والسقف — سؤال حاسم

| السيناريو | الحجم التقديري | الحكم |
|:---|:---|:---|
| صف واحد (محتوى + صوت + SVG) | 6–8MB | ✅ داخل السقف |
| صفان | 12–16MB | ✅ داخل السقف |
| ستة صفوف | 36–48MB | ❌ يتجاوز 25MB |

### الخيارات المعروضة

| الخيار | الوصف | التوصية |
|:---|:---|:---|
| **أ. حزمة لكل صف** | APK أو حزمة محتوى منفصلة لكل صف | الأنظف، يُحلّ الترخيص لاحقاً |
| **ب. رفع السقف إلى ~45MB** | أبسط للمستخدم، أثقل للتنزيل | مقبول إذا لم يُضاف صوت لكل صف |
| **ج. حزمة الصف الأول فقط في الإصدار الأول** | الأكثر أماناً للميزانية والوقت | ✅ **توصيتي الحالية** |

**توصيتي:** الخيار (ج) فوراً، مع تصميم البيانات منذ اليوم على أن «الحزمة = صف + مادة + إصدار»، حتى لا يصير الخيار (أ) إعادة هيكلة.

## 16. المقاييس — ما نقيسه فعلاً

| المقياس | التعريف | الهدف الأولي |
|:---|:---|:---|
| نسبة الإتقان المستقل | مهارات ظهرت مستقلة ÷ مهارات جُرّبت | ≥ 40% بعد أسبوعين |
| معدل طلب التلميح | تلميحات ÷ تفاعلات | 15–30% |
| نجاح التوقف | جلسات انتهت بزر «نوقف هون» بلا إحباط | ≥ 90% |
| العودة الطوعية | عودة خلال 72 ساعة بلا إلحاح | ≥ 50% |
| فك التعليمة | نسبة إتمام النشاط الأول بدون مساعدة | ≥ 70% للصف 1–2 |
| أداء الجهاز | متوسط الإطارات، زمن الفتح | 60/30fps، < 3ث |

**ما لا نقيسه ولا نعرضه:** مدة الشاشة، عدد الفتحات, «أفضل طفل»، أو أي ترتيب بين الأطفال.
