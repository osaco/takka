# takka — تطبيق تعليمي ترفيهي لأطفال غزة

[![License: GPL-3.0](https://img.shields.io/badge/License-GPL%203.0-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.6-blue.svg)](https://www.typescriptlang.org/)
[![React](https://img.shields.io/badge/React-18-61dafb.svg)](https://react.dev/)

> **تكة** — محرك إتقان تعليمي عربي أوفلاين 100% لأطفال غزة (الصفوف 1-6).

---

## 🎯 ما هو تكة

تكة تطبيق تعليمي ترفيهي يركّز على:
- **العربية** (الحروف، الكلمات، الجمل)
- **الرياضيات** (الأرقام، الجمع، الطرح)

في المرحلة الأولى (MVP): **الصف الأول** فقط.

### المبادئ الحاكمة
- ✅ أوفلاين 100%
- ✅ خفيف الوزن (< 25MB)
- ✅ أمان الخطأ (لا أحمر صارخ، لا لوم)
- ✅ محتوى موثّق المصدر
- ✅ لا تتبع، لا هوية، لا إنترنت

---

## 🏗️ المكدس التقني

| الطبقة | التقنية |
|:---|:---|
| الواجهات | React 18 + TypeScript |
| العالم | Canvas 2.5D |
| الحالة | Zustand |
| التحقق | Zod |
| التخزين | Dexie (IndexedDB) |
| الصوت | Howler.js |
| الغلاف | Capacitor 6 → APK |
| الاختبار | Vitest |

---

## 🚀 البدء

```bash
# تثبيت الاعتمادات
pnpm install

# تشغيل Development
pnpm dev

# تشغيل الاختبارات
pnpm test

# بناء الإنتاج
pnpm build

# بناء APK Android
pnpm capacitor:sync
pnpm capacitor:android
```
