## 5. قواعد الاعتماد بين الطبقات

```
لا يمكن لـ domain أن يستورد من runtime أو data
لا يمكن لـ runtime أن يستورد من templates مباشرة (templates تستورد من domain فقط)
data تستورد من domain فقط (نفس واجهة Repository)
tools تستورد من domain فقط
```
