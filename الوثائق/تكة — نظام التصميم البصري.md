## 1. فلسفة التصميم

> **«مغامرة هادئة»** — الإحساس الوحيد المعتمد للمالك.  
> الألوان دافئة وهادئة، لا صارخة. لا أحمر تحذيري. لا ازدحام بصري. كل عنصر يخدم الراحة النفسية للطفل الغزي الذي يعيش في بيئة مليئة بالتوتر.

### المبادئ الحاكمة

| المبدأ | التطبيق |
|:---|:---|
| **الهدوء أولاً** | خلفيات دافئة، تباين معتدل، لا ألوان نيون |
| **وضوح النص العربي** | Tajawal خط رئيسي، تشكيل واضح، أحجام كبيرة (20px+) |
| **أمان الخطأ** | برتقالي دافئ بدل أحمر، حركة اهتزاز لطيفة بدل صوت تنبيه |
| **هدف لمس كبير** | أزرار ≥ 56dp، هوامش أمان ≥ 16dp |
| **إتاحة كاملة** | لا يعتمد اللون وحده، يدعم `prefers-reduced-motion` |

## 3. التيبوغرافيا

### الخط الرئيسي
- **الاسم:** `Tajawal` (مفتوح المصدر)
- **الصيغة:** WOFF2 محمّل محلياً (< 200KB)
- **الخيارات البديلة:** `Readex Pro`

### أحجام الخطوط

| السياق | الحجم | الوزن | Line-height |
|:---|:---|:---|:---|
| عنوان شاشة | 28px | Bold (700) | 1.3 |
| عنوان قسم | 24px | SemiBold (600) | 1.4 |
| نص تعليمات | 20px | Regular (400) | 1.6 |
| نص نشاط | 20px | Regular (400) | 1.6 |
| تلميح | 18px | Regular (400) | 1.5 |
| نص ثانوي | 16px | Regular (400) | 1.5 |
| رقم/إشارة | 14px | Medium (500) | 1.4 |

### قواعد التشكيل
- جميع الحركات (فتحة، ضمة، كسرة، سكون) يجب أن تظهر بدقة
- لا تداخل بين الحركات والأسطر
- الاختبار البصري إلزامي قبل اعتماد أي نص

| التفاعل | المدة | التأثير |
|:---|:---|:---|
| نقر | فوري | feedback بصري هادئ (تكبير خفيف) |

| احتفال (نجاح) | 500ms | وميض ذهبي + صوت خشبي خفيف |

## 5. نظام الصوت

### فلسفة الصوت
أصوات آلات خشبية وماريمبا وأوتار دافئة — بعيدة تماماً عن التنبيهات الإلكترونية الحادة.

### المكتبة الصوتية

| النوع | الصيغة | المعدل | العدد التقديري | الحجم |
|:---|:---|:---|:---|:---|
| تعليمات أنشطة | Opus mono | 24kbps | ~60 مقطوعة | ~720KB |
| حروف وتشكيل | Opus mono | 24kbps | ~84 مقطوعة | ~500KB |
| بنك كلمات | Opus mono | 24kbps | ~600 مقطوعة | ~2.7MB |
| تغذية راجعة | Opus mono | 24kbps | ~40 مقطوعة | ~360KB |
| مؤثرات عالمية | Ogg mono | 32kbps | ~20 مقطوعة | ~240KB |
| **الإجمالي** | | | | **~4.5MB** |

### قواعد الصوت
- **اختياري دائماً:** يمكن إيقافه بالكامل من إعدادات ولي الأمر
- **لا معلومة حصراً بالصوت:** النص والصورة يبقيان
- **لا تشغيل تلقائي:** ينفّذ فقط عند طلب الطفل
- **صامت بفرض الطبيعة:** في الأوضاع المنخفضة (Low-power mode)

## 6. شاشات التدفق الرئيسية

### تدفق المستخدم الأساسي

```
Splash (التميمة + شعار) → خريطة الأرخبيل → اختيار الجزيرة →
شاشة النشاط → الاحتفال → العودة للخريطة
```

### شاشات ولي الأمر

```
ملف رمزي → اختيار الصف والصوت → عرض التقدم → بلاغ خطأ → تصدير/استيراد JSON
```

### تفاصيل الشاشات

#### شاشة البداية (Splash)
- التميمة «شعلة» ذهبية متوهجة بملامح سعيدة
- شعار «تكة» بخط Tajawal Bold
- خلفية بحر هادئة بتدرج
- مدة العرض: 1.5 ثانية (لا انتظار مطول)

#### خريطة الأرخبيل (World Map)
- جزر عائمة بأسلوب Canvas 2.5D
- كل جزيرة تمثل مادة/وحدة منشورة
- شارة ذهبية على الجزر المكتملة
- بحر متحرك بهدوء (حركة طبيعية)
- أيقونة «فطين» الرفيق في زاوية

#### شاشة النشاط (Activity Canvas)
- خالية تماماً من الشريط العلوي المعقد
- زر «عودة» كبير في الزاوية (≥56dp)
- «فطين» يقف في الأسفل يراقب ويشجع
- المحتوى في وسط الشاشة (منطقة الإبهام)

#### نافذة الاحتفال (Success Modal)
- اهتزاز كنزي خفيف
- صوت خشبي دافئ
- رسالة تشجيعية: «أتقنت! الجزيرة ازدهرت!»
- زر «تابع» و «ارجع للخريطة»

## 8. معايير الإتاحة (Accessibility)

| المعيار | القيمة |
|:---|:---|
| تباين النص على الخلفية | ≥ 4.5:1 (WCAG AA) |
| تباين عناصر واجهة | ≥ 3:1 |
| دعم تقليل الحركة | `prefers-reduced-motion: reduce` |
| قارئ الشاشة | كل عنصر تفاعلي له `aria-label` |
| التركيز المنطقي | ترتيب تبويب واضح RTL |
| تكبير النص | يدعم حتى 200% دون كسر layout |
