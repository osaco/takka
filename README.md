# مشروع تكة

مساحة العمل الرئيسية لتطبيق تكة التعليمي للأطفال. **`تكة.md`** هو دستور المنتج، و**`SPEC.md`** يصف نطاق النسخة التجريبية المحلية.

## التطبيق النشط

التطبيق الحالي موجود في **`التطبيق/`** ويستخدم React وTypeScript وVite. يتضمن محرك الإتقان، جلسات التعلم، الجزر، حزم المحتوى، التخزين المحلي، والقوالب التفاعلية. ملفات النسخة السابقة المبنية بـNext.js محفوظة في **`التطبيق/legacy-next/`** للرجوع إليها؛ المسار النشط هو تطبيق Vite في جذر `التطبيق/`.

## تشغيل التطبيق

من مجلد المشروع:

```powershell
npm install --prefix التطبيق
npm run dev
```

أوامر البناء والفحص المعرّفة في `package.json` الجذري تمررها إلى التطبيق. لم تُفعّل المزامنة السحابية في النطاق الحالي.

## خريطة المجلدات

- **`تكة.md`** — دستور المنتج ومبادئ التعلم والخصوصية والجاذبية الصحية.
- **`SPEC.md`** — نطاق النسخة التجريبية وقراراتها المحلية.
- **`DESIGN.md`** — مسودة النظام البصري.
- **`التطبيق/src/`** — النواة النشطة وطبقات التشغيل والبيانات والمحتوى.
- **`التطبيق/legacy-next/`** — نسخة Next.js السابقة، محفوظة كما كانت مع شيفرتها واختباراتها وإعداداتها.
- **`الوثائق/`** — خطط البناء، معمارية الجزيرة، أبحاث التصميم والتربية، وخريطة الصف الأول.
- **`المراجع/`** — مصادر المشروع؛ ملفات الكتب PDF تبقى محلية ولا تُرفع إلى GitHub.
- **`العمل/`** و**`تقارير البوتات/`** — مخرجات التخطيط والتصميم والتدقيق والتقارير.

## ملاحظة عن المحتوى

وجود حزمة أو اجتيازها للفحص التقني لا يعني اعتمادها تربويًا أو تغطيتها للمنهاج. تُراجع الحزم مع مصادرها قبل وصفها كمحتوى تعليمي معتمد.
