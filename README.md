# مشروع تكة

هذه مساحة العمل الرئيسية لمنتج تكة. **`تكة.md`** هو دستور المنتج؛ وتحدد **`SPEC.md`** نطاق النسخة التجريبية. اقرأ هذين الملفين قبل تعديل تجربة الطفل أو إضافة محتوى.

## الحالة الحالية

- يحتوي [التطبيق](التطبيق/README.md) على MVP ويب مبني بـNext.js: جزيرة واحدة، ثلاث محطات تعلم تجريبية، تلميحات، تقدم محلي، مهمات، ومكافأة ثابتة معلومة الشرط.
- التشغيل الحالي محلي أولاً؛ لا تظهر مسارات حسابات الأسرة أو مزامنة Supabase افتراضياً. تجهيزات Supabase من المرحلة السابقة باقية لمرحلة لاحقة، ولم تُجرَ عليها عمليات ضمن الترتيب الحالي.
- فطين واللوحة اللونية والاتجاه العربي RTL موجودة في النموذج. التفاصيل الفنية النهائية للشخصية والنظام البصري ما زالت بحاجة مراجعة واعتماد.
- المحطات الثلاث عينة محايدة لا تمثل تغطية لمنهاج معتمد. خريطة الصف الأول ما زالت وثيقة تخطيط منفصلة وتحتاج اعتماداً قبل إدخال دروس حقيقية.
- النسخة الحالية تأسيس قابل للمراجعة، وليست إصداراً إنتاجياً مكتملاً. جزيرة v4 ذات المباني التسعة والاقتصاد الكامل ومسارات المحتوى المستقبلية ليست منفذة بالكامل بعد.
- خلاصة مقارنة التطبيق بمبادئ المنتج في [مراجعة توافق الـMVP مع تكة](العمل/مراجعة%20المنتج/مراجعة%20توافق%20الـMVP%20مع%20تكة.md).

## خريطة المجلدات

- **`تكة.md`** — دستور المنتج ومبادئ التعلم والخصوصية والجاذبية الصحية.
- **`SPEC.md`** — نطاق التطبيق وقرارات التنفيذ؛ يوضح أعلى الملف أن الحسابات والمزامنة مؤجلة حالياً.
- **`DESIGN.md`** — مسودة النظام البصري وقراراتها غير المعتمدة.
- **`التطبيق/`** — كود MVP، إعداداته، واختباراته.
- **`الوثائق/`** — خطط البناء، معمارية الجزيرة، أبحاث التصميم والتربية، وخريطة الصف الأول. الوثائق تخطيطية ما لم تُعتمد صراحةً.
- **`المراجع/رزم غزة/`** — فهرس وبيانات مصادر الرزم؛ ملفات PDF محلية ومستثناة من Git.
- **`العمل/التصميم/`** — المعاينة التفاعلية والطلبات والمسودات البصرية.
- **`العمل/تدقيق المنهاج/`** و**`العمل/البحث التربوي/`** — مخرجات تدقيق المنهاج ومذكرات الأدلة.
- **`العمل/مهارات البوتات/`** — تعريفات ومهارات الفريق المرجعية.
- **`العمل/تقارير البوتات/`** — التقارير المرحلية، الأدلة، معاينات الصور ومسوداتها. افتح [فهرس التقارير](العمل/تقارير%20البوتات/README.md).
- **`تقارير البوتات/`** — فهرس سريع للتقارير الموجودة تحت مجلد العمل.

## التحقق المحلي

من مجلد `التطبيق/` شغّل `npm run dev` للمعاينة. أوامر التحقق: `npm run typecheck` و`npm run lint` و`npm run build` و`npm run test:e2e`.

## ملفات الكتب

ملفات PDF التعليمية محفوظة محلياً داخل `المراجع/رزم غزة/` ومجلدات البحث؛ وهي مستثناة من GitHub. يحتوي المستودع على ملفات التوثيق وبيانات فهرسة المصادر دون نسخ الكتب.
