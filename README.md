# مشروع تكة

هذه مساحة العمل الرئيسية لتطبيق تكة. ابدأ بقراءة **تكة.md**؛ الملف يجمع دستور المنتج، الماستر برومبت العام، برومبتات المراحل، قرارات المنهاج والصوت والخصوصية والدفع، ومخرجات المرحلتين الأولى والثانية.

## حالة العمل

- مسودة النظام البصري 0.1 ومعاينة HTML جاهزتان ببيانات افتراضية؛ أقر المالك إحساس المغامرة الهادئة فقط، وتنتظر بقية التفاصيل المراجعة والاعتماد. لا محتوى منهجي ولا كود إنتاجي.
- خريطة الصف الأول 0.2: تمت مراجعتها مع Argon ودمج تحفظاته؛ تنتظر اعتماد المالك، مع إبقاء قياس الطول والزمن قيد تحقق بصري موجّه.
- لا يوجد كود تطبيق أو اختيار إطار تقني بعد.
- الترتيب الحالي: تصميم واعتماد نظام الواجهات ببيانات افتراضية؛ ثم اعتماد خريطة الصف الأول وإدخال عينة موثقة؛ ثم تدقيق وإدخال الصفين الثاني والثالث بالترتيب. يحدد المالك نطاق الـMVP بعدها. خريطة الصف الأول الحالية وثيقة مصادر منفصلة راجعها Argon سابقاً؛ نقاشها لا يعني إدخال مواد. لا تظهر دروس حقيقية في الواجهات قبل اعتماد النظام والخريطة.
- لا نصف رزم غزة المتاحة بأنها المنهاج المعتاد الكامل أو بأنها تغطي الفصلين كاملين دون مصدر يثبت ذلك.

## ترتيب المجلدات

- **DESIGN.md** — مسودة النظام البصري الأولي؛ قراراته غير معتمدة عدا الإحساس العام الذي أقره المالك.

- **تكة.md** — دستور المشروع، الماستر برومبتات، وموجز مخرجات المراحل.
- **الوثائق/** — حزمة التخطيط الكاملة (40 ملف Markdown): خطة البناء وحزم P0–P6 والرؤية المعمارية وأبحاث آليات التعليم؛ مرجع تخطيطي لا اعتماد.
- **المراجع/رزم غزة/** — ملفات PDF الأصلية، manifest.csv، وREADME مصدر الحزم.
- **العمل/التصميم/** — معاينة النظام الأولي ومخرجات التصميم؛ المسودات لا تصبح معتمدة حتى يوافق المالك.
- **العمل/تدقيق المنهاج/** — تقرير الصف الأول وخطط تدقيق الصفوف التالية.
- **العمل/البحث التربوي/** — مذكرة الأدلة وخلاصة نقاش Argon.
- **التطبيق/** — مساحة كود التطبيق؛ تبقى التقنية غير مختارة حتى اجتياز بوابتها.

## ملفات الكتب

ملفات PDF التعليمية محفوظة محلياً داخل المراجع/رزم غزة/، لكنها مستثناة من GitHub. يحتوي المستودع على ملفات الأساس والتوثيق وبيانات فهرسة المصادر فقط.
